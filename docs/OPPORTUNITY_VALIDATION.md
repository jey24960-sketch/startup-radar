## 표본 누락 측정: 분모와 한계

2026-09-15 공식 페이지의 제한된 표본 9개 모집(SNU 1, KAIST 1, MARU 1, D2SF 5, Antler 1)을 대조했다. 스파크랩 소개 1개는 비모집 음성 대조군이다. 수집·저장 10개, 모집 확인 9개, 회원 조회 9개, 모집 표본 누락 0/9(0%)였다. 과거 종료 모집 1개도 보존한다. 현재 모집 중 2, 상시 2, 날짜 확인 불가 4, 마감 1로 구분했다.

날짜 확인은 모집 9개 중 3개(33.3%), 신청 링크 확인은 5개(55.6%)다. 스파크랩을 포함한 전체 저장 10개 기준 관리자 지표는 3/10·5/10으로 분모가 다르다. 링크가 없으면 이메일·HTTP 링크·첨부를 임의로 HTTPS 신청 폼으로 바꾸지 않았다. D2SF 공고 사이의 공통 URL은 자동 병합하지 않고 중복 검토 후보로 남을 수 있다.

이 표본은 목적 표집이며 임의 표본·전국 조사·기관 전체 기간 조사가 아니다. 연결하지 못한 기관·페이지 상한 밖의 오래된 글·이미지/PDF 전용 정보가 분모에서 빠져 있다. 유형별 표본은 경진대회 2, 배치 2, 기업 협업 1, 교육·공간 1, 투자 검토 2, 행사 1이다. 공공지원은 이번 표본 0건이다. 원문 게시 시각을 모든 출처에서 검증하지 못해 발견 지연은 미측정이다. 전국 포괄률이나 대한민국 대부분을 수집한다는 주장에 사용할 수 없다.

서울대 공식 129번 기후테크 창업 경진대회를 홈페이지 링크에서 발견해 상세 본문을 읽었다. 신청 기간의 명시된 연도로 2026-09-15 마감을 저장했다. 기존 programs / program_versions / program_source_snapshots에 원문과 버전을 남기고 opportunity_records에 회원 표시 정보를 연결했다. 프로필 없는 가상 GFC 회원의 실제 SQL RPC에서 목록·상세 조회를 확인했다. 이 실제 수집 자료의 축약본으로 GFC 브라우저에서 목록·상세·제보 흐름까지 검증했다.

같은 로컬 실행에서 주간 공지 1개에 신규 6건을 포함했다. 상시 2건과 마감된 MARU 배치, 모집 미확인 스파크랩 소개는 제외했다. Telegram 상태는 DELIVERY_DISABLED, 발송/대기 메시지 행은 0개였다. 운영 웹에 테스트 공지를 게시하거나 실제 사용자의 수신 설정을 변경하지 않았다.

## 테스트와 산출물

- Python 전체: 475 통과, 14 선택 환경 테스트 제외. 직접 관련 수집·권한·정정·주간 회귀 묶음: 50 통과.
- 후속 변경 확인: 기존 주간 해시·초기 배포 경로 3개, 외부 링크 안전성·선택 연결·수집 건강도 29개, 상세 재확인·정정 보존 2개 통과. 새 6개 테이블 RLS, 직접 쓰기 차단, 익명 함수 권한 차단, private definer·FK 인덱스 검토 통과.
- GFC Node/공유 DB 회귀: 83 통과. Vite production build 성공. 기존 번들 크기/Browserslist 권고 경고는 빌드 실패가 아니다.
- 브라우저: 회원 목록·상세·제보, 관리자 정정·이력·동시 충돌·매일 시간·기관 요청, 기존 주간 설정·공지 정정 및 비관리자 거부 확인. 실제 SQL 함수를 사용하는 테스트이며 실제 로그인 계정을 새로 만들지 않았다.
- 초기에 발견한 결과 직렬화 오류와 아산 본문 선택자, 입력 레이블 접근성 문제를 수정했다. 관련 검증만 재실행했으며 정상 출처 전체를 반복 수집하지 않았다.
- `opportunity-source-sample.json`: 공식 표본과 결과. `tools/check_opportunity_sources.py`: 명시적으로 표시한 로컬 폐기용 DB에서만 실행하는 실제 수집 확인 도구. `OPPORTUNITY_OPERATIONS.md`: 비개발자 운영·적용·복구 방법.

## 아직 필요한 것

운영 마이그레이션과 두 저장소 배포, 원하는 채널 활성화, 매일 수집 시각·기존 주간 발행 시각 확인이 필요하다. 신규 서비스 비밀값은 프런트엔드에 넣지 않는다. 뉴스레터·검색 공급자·동적 사이트 브라우저 파서·이미지/PDF 선택적 추출은 연결하지 않은 상태를 유지한다. 긴급 후보는 제공하지만 긴급 발송은 아직 제공하지 않는다. 신뢰할 수 있는 날짜·대상 확인 비율을 높이는 출처별 파서는 후속 작업이다.
